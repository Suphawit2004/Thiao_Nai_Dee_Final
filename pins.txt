# วิธีเอาพิกัดจาก Google Maps app:
#   1. เปิดแอป Google Maps ค้นหา/เดินหน้าจอไปที่หน้าร้าน
#   2. กดค้างตรงจุดที่เป็นตัวร้าน (จะมีหมุดแดงโผล่)
#   3. ตัวเลขพิกัดจะขึ้นในแถบล่าง เช่น "19.163550, 99.900650"
#   4. วางต่อท้ายบรรทัด slug ของร้านนั้นในด้านล่าง (บรรทัดเดียวกัน)
#
# รูปแบบบรรทัด:  slug latitude longitude   (ต้องอยู่บรรทัดเดียวกัน)
#   - มีหรือไม่มี comma ก็ได้, คั่นด้วยช่องว่าง
#   - ร้านไหนยังไม่กรอก = ใช้พิกัดเดิม (ไม่ผิดพลาดอะไร)
